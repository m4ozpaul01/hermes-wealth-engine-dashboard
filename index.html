How it works

Token discipline. The supervisor makes no LLM calls of its own. All scraping, hashing, parsing, indexing and static builds are deterministic local code. Before any external payload is processed, its SHA-256 is compared against a local ledger — an unchanged internet costs exactly zero tokens. A hard monthly cap governs paid API spend; when it is reached, work is rerouted to a local language model rather than stalling.

Immutable source layer. Every retrieved payload is written to an append-only raw/ directory before synthesis, so any summarised page can be re-derived from an untouched record.

Degradation, not silence. Each data source reports count / cached / stale / error provenance. A transient rate-limit serves the last known good payload flagged as stale — an empty result is never allowed to masquerade as "no data".

Self-evolution. Agents version themselves after every task: telemetry critique, prompt mutation, tool extraction, version increment. The history is append-only and auditable.

What it cannot do. It cannot open accounts, pass identity verification, accept a payout, or fund a brokerage. Those are the only things standing between this system and its first euro, and they require a person.
